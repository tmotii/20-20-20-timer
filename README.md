# 20-20-20 タイマー

目の疲れをやわらげる「20-20-20ルール」(20分ごとに、20秒間、6m以上先を見る)のためのブラウザタイマーです。

- 作業20分 → 休憩20秒を自動で繰り返します(時間は設定で変更できます)
- 音・バイブ・通知(許可した場合)でお知らせします
- 別のアプリを開いていても動くよう、無音の音声で通知欄に表示します(Android Chrome向け)
- 今日の休憩回数を、ブラウザ内にだけ保存します

`index.html` 1ファイルだけで動きます。外部に送信するデータはありません(フォントのみ Google Fonts を読み込みます)。

近視を治すものではなく、近くを見続けた目を休めるための習慣づけの道具です。
